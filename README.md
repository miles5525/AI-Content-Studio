# AI Content Studio

AI Content Studio is a WordPress plugin in active development for creating, optimizing, managing, and publishing content with AI. Task 1 provides only the plugin foundation; AI functionality has not been added yet.

## Requirements

- WordPress 6.4 or newer
- PHP 8.0 or newer

## Installation

1. The plugin is currently installed at `C:\xampp\htdocs\supportcandy-ai-test\wp-content\plugins\AI Content Studio`.
2. Activate **AI Content Studio** from **Plugins → Installed Plugins**.
3. Open **AI Content Studio** in the WordPress administration menu.

## Development status

Version `0.1.0` provides the plugin bootstrap, activation and deactivation handlers, installation metadata, centralized permissions, scoped admin assets, and placeholder admin screens. It does not include settings forms, AI integrations, content generation, social-media functionality, or custom database tables.

## Placeholder admin pages

- Dashboard
- Content Ideas
- Create Content
- Content History
- Brand Profile
- Settings
- System Status
